이제 데이터 저장 로직을 구현해줘.

데이터 모델은 다음과 같아:
{
id: string (고유 식별자, timestamp 기반으로 생성),
text: string (할 일 내용),
category: "업무" | "개인" | "공부",
completed: boolean,
createdAt: number (timestamp)
}

요구사항:

1. 모든 할 일 데이터는 배열 형태로 localStorage의 "todos" 키에 JSON으로 저장해줘.
2. 페이지 로드 시 localStorage에서 기존 데이터를 불러와서 화면에 렌더링하는 함수를 만들어줘.
3. 데이터를 저장하는 saveTodos(), 불러오는 loadTodos() 같은 함수로 로직을 분리해줘.
4. localStorage에 데이터가 아예 없을 때(최초 실행)는 빈 배열로 시작하도록 처리해줘.
5. 아직 추가/수정/삭제 UI 로직은 연결하지 않아도 되고, 콘솔에서 임의로 테스트 데이터를 넣었을 때 새로고침해도 유지되는지만 확인 가능하게 만들어줘.
