1단계에서 만든 UI와 2단계에서 만든 저장 로직을 연결해서, 다음 기능들을 구현해줘.

1. 할 일 추가
    - 입력창에 텍스트를 쓰고 등록 버튼 클릭 또는 Enter 시 목록에 추가
    - 텍스트가 비어있거나 공백만 있으면 추가되지 않도록 막아줘
    - 추가 시 선택된 카테고리도 함께 저장

2. 할 일 수정
    - 항목을 클릭하거나 별도 수정 버튼을 눌러 텍스트를 편집할 수 있게 해줘
    - 수정 완료 시 즉시 저장 및 화면 반영

3. 할 일 삭제
    - 각 항목에 삭제 버튼을 두고, 클릭 시 목록과 localStorage에서 즉시 제거

4. 완료 체크
    - 각 항목에 체크박스를 두고, 체크 시 취소선 등으로 완료 스타일 적용
    - 다시 클릭하면 미완료 상태로 되돌아가야 함

모든 변경 사항(추가/수정/삭제/체크)은 즉시 localStorage에 반영되어야 하고, 새로고침 후에도 그대로 유지되어야 해. 목록이 비어있을 때는 안내 문구가 보이고, 항목이 하나라도 있으면 안내 문구는 숨겨줘.
