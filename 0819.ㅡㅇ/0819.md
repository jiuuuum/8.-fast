개인용 할 일 관리 웹앱을 만들 거야. 순수 HTML/CSS/JavaScript로 만들고, 프레임워크는 쓰지 않아.

다음 3개 파일로 프로젝트 구조를 만들어줘:

- index.html
- style.css
- script.js (아직 로직은 비워둬도 됨)

index.html에는 다음 요소들을 위한 기본 마크업만 구성해줘 (기능은 다음 단계에서 구현):

1. 할 일 입력창 + 카테고리 선택(업무/개인/공부) + 등록 버튼
2. 진행률을 보여줄 영역 (예: "완료 0 / 0 (0%)")
3. 할 일 목록이 렌더링될 빈 컨테이너
4. 목록이 비어있을 때 보여줄 안내 문구 요소 ("할 일이 없습니다" 등)

밝고 깔끔한 스타일을 기본 톤으로 하고, style.css에 대략적인 레이아웃(중앙 정렬, 카드형 UI 등)만 잡아줘. 세부 디자인은 이후 단계에서 다듬을 거야.
